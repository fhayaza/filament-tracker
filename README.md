# Filament Tracker 🧵

Aplikasi visual reminder dan pelacak stok sisa spul filamen 3D printing kantor/workshop secara *real-time*.

## Fitur
- 🎨 **Visual Container:** Tampilan level sisa stok filamen dalam bentuk kapsul horizontal dengan warna filamen asli.
- ⚡ **Real-Time Cloud Sync:** Terhubung dengan Google Firebase Firestore — perubahan sisa filamen di HP langsung terupdate di laptop dan sebaliknya.
- 🌓 **Dark & Light Mode:** Mendukung tema gelap dan terang yang nyaman untuk penggunaan workshop.
- 📱 **Mobile Responsive:** Desain responsif ramah jempol untuk layar ponsel pintar.
- 💾 **Offline Fallback & Backup:** Tetap berfungsi normal saat offline (`localStorage`) dengan fitur ekspor/impor JSON cadangan data.

## Teknologi
- HTML5, Vanilla CSS, Modern JavaScript
- Google Firebase Firestore (Real-time Cloud Sync)
- Vercel Deployment Ready
